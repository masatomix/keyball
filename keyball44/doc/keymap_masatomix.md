# Keyball44 masatomix キーマップ

Keyball44 用の masatomix カスタムキーマップの全レイヤー可視化。

- ソース: `keyboards/keyball/keyball44/keymaps/masatomix/`
- レイアウト: `LAYOUT_universal`（= `LAYOUT_no_ball`）
- レイヤー数: 7（`DYNAMIC_KEYMAP_LAYER_COUNT 7`、実装は Layer 0,1,2,3,6）

## 独自機能

| 機能 | ファイル | 説明 |
|---|---|---|
| Layer LED | `layer_led.c` | マウスレイヤー(Layer 3)でLEDをHSV_AZUREに点灯、他レイヤーは消灯。`LAY_TOG`でON/OFF |
| Precision | `precision.c` | `PRC_SW`押下中にCPIを300に低下、離すと復帰 |
| Auto Mouse | config.h | トラックボール操作でLayer 3へ自動遷移（400ms後に復帰） |

## config.h 主要設定

```c
#define KEYBALL_CPI_DEFAULT 700
#define KEYBALL_SCROLL_DIV_DEFAULT 6
#define POINTING_DEVICE_AUTO_MOUSE_ENABLE
#define AUTO_MOUSE_DEFAULT_LAYER 3
#define AUTO_MOUSE_TIME 400
#define LAYER_LED_ENABLE
#define PRECISION_ENABLE
#define PRECISION_CPI 3              // CPI 300
#define DYNAMIC_KEYMAP_LAYER_COUNT 7
#define KEYBALL_SCROLLSNAP_ENABLE 0
#define MOUSE_LED_COLOR HSV_AZURE
```

## rules.mk

```makefile
RGBLIGHT_ENABLE = yes
OLED_ENABLE = yes
VIA_ENABLE = yes

```

## Layer 1: ナビゲーション（LT1 = Space / Enter 長押し）

```
┌──────┬──────┬──────┬──────┬──────┬──────┐          ┌──────┬──────┬──────┬──────┬──────┬──────┐
│ F11  │C(↑)  │C(↓)  │ PgUp │  ↑   │      │          │      │      │      │ PgUp │  ↑   │      │
├──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┼──────┤
│S+Ctrl│ Vol- │ Vol+ │ DEL  │  →   │Alt+  │          │  BS  │  ↓   │  ↑   │  →   │      │      │
│      │      │      │      │      │ ESC  │          │      │      │      │      │      │      │
├──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┼──────┤
│      │ BTN4 │ BTN5 │ PgDn │  ↓   │  ←   │          │  ↓   │  ←   │      │ PgDn │      │      │
│      │ 戻る │ 進む │      │      │      │          │      │      │      │      │      │      │
└──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┘
       │      │      │      │▓HOLD▓│      │          │ DEL  │▓HOLD▓│      │      │      │
       └──────┴──────┴──────┴──────┴──────┘          └──────┴──────┴──────┴──────┴──────┘
```

**特徴:**
- `C(↑)` / `C(↓)` = Ctrl+Up/Down（仮想デスクトップ切替）
- `Alt+ESC` = アプリ切替
- 左右両手に矢印キーをミラー配置
- **Layer 1 では Auto Mouse が無効化される**（ナビ操作中にマウスレイヤーに飛ばない）

## Layer 2: 設定・Fキー・RGB（LT2 = LNG2 長押し）

```
┌──────┬──────┬──────┬──────┬──────┬──────┐          ┌──────┬──────┬──────┬──────┬──────┬──────┐
│ VAL- │ VAL+ │      │GUI+E │      │      │          │      │Alt+  │PrtSc │      │      │      │
│      │      │      │      │      │      │          │      │PrtSc │      │      │      │      │
├──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┼──────┤
│ SAT- │ SAT+ │  F2  │  F3  │  F4  │  F5  │          │  F6  │  F7  │  F8  │  F9  │ F10  │ F11  │
├──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┼──────┤
│ HUE- │ HUE+ │  F1  │      │ LAY  │ RGB  │          │ CPI  │ CPI  │SCRL  │SCRL  │ KBC  │ F12  │
│      │      │      │      │ TOG  │ TOG  │          │ -100 │ +100 │ DV-  │ DV+  │ SAVE │      │
└──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┘
       │      │      │      │      │▓HOLD▓│          │      │      │      │      │ KBC  │
       │      │      │      │      │      │          │      │      │      │      │ RST  │
       └──────┴──────┴──────┴──────┴──────┘          └──────┴──────┴──────┴──────┴──────┘
```

**特徴:**
- `GUI+E` = エクスプローラ起動（Windows）
- `Alt+PrtSc` = アクティブウィンドウのスクリーンショット
- `LAY_TOG` = Layer LED 機能の ON/OFF 切替
- `RGB_TOG` = RGB LED の ON/OFF
- `KBC_SAVE` / `KBC_RST` = Keyball 設定の EEPROM 保存/リセット
- `CPI_D100` / `CPI_I100` = マウス感度 ±100 調整
- `SCRL_DVD` / `SCRL_DVI` = スクロール分割値調整

## Layer 3: マウス（Auto Mouse 自動遷移 + LT3 ホールド）

```
┌──────┬──────┬──────┬──────┬──────┬──────┐          ┌──────┬──────┬──────┬──────┬──────┬──────┐
│      │      │      │      │      │      │          │      │      │      │      │      │      │
├──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┼──────┤
│      │      │      │      │      │      │          │      │ BTN1 │ BTN3 │ BTN2 │      │      │
│      │      │      │      │      │      │          │      │ 左ｸﾘ │ 中ｸﾘ │ 右ｸﾘ │      │      │
├──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┼──────┤
│      │ BTN4 │ BTN5 │      │      │PRC_SW│          │      │ BTN4 │ BTN5 │      │      │      │
│      │ 戻る │ 進む │      │      │精密  │          │      │ 戻る │ 進む │      │      │      │
└──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┘
       │      │      │      │ BTN1 │      │          │      │      │      │      │      │
       │      │      │      │ 左ｸﾘ │      │          │      │      │      │      │      │
       └──────┴──────┴──────┴──────┴──────┘          └──────┴──────┴──────┴──────┴──────┘
```

**特徴:**
- **Auto Mouse**: トラックボールを動かすと自動で Layer 3 に遷移（400ms 後に復帰）
- `PRC_SW` = **Precision モード**（押下中 CPI 300 に低下、離すと復帰）
- `LT(3,F)` / `LT(3,.)` のホールドでも手動遷移可能
- **LED**: Layer 3 に入ると LED が `HSV_AZURE` に点灯
- 左手親指に `BTN1`、右手ホームポジションに `BTN1`/`BTN2`/`BTN3` を配置
- 左右に `BTN4`(戻る) / `BTN5`(進む) を配置

## Layer 6: 記号・数字（MO(6) / LT(6,`) ホールド）🔄 スクロールモード

```
┌──────┬──────┬──────┬──────┬──────┬──────┐          ┌──────┬──────┬──────┬──────┬──────┬──────┐
│  ~   │  !   │  @   │  #   │  $   │  %   │          │  ^   │  &   │  *   │  (   │  )   │  _   │
├──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┼──────┤
│CTL_T │  1   │  2   │  3   │  4   │  5   │          │  6   │  7   │  8   │  9   │ LT4  │CTL_T │
│  `   │      │      │      │      │      │          │      │      │      │      │  0   │  -   │
├──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┼──────┤
│ LNG1 │ BTN4 │ BTN5 │      │  {   │  [   │          │  ]   │  }   │      │      │      │      │
│英数  │ 戻る │ 進む │      │      │      │          │      │      │      │      │      │      │
└──────┼──────┼──────┼──────┼──────┼──────┤          ├──────┼──────┼──────┼──────┼──────┘
       │      │      │▓HOLD▓│      │      │          │      │      │      │      │▓HOLD▓│
       └──────┴──────┴──────┴──────┴──────┘          └──────┴──────┴──────┴──────┴──────┘
```

**特徴:**
- 上段: Shift 記号（`! @ # $ % ^ & * ( ) _`）
- 中段: 数字行（1〜9, 0）
- 下段: 括弧ペア `{ [` / `] }`、`LNG1`(英数切替)
- **Layer 6 ではトラックボールがスクロールモードになる**
- `LT(4, 0)` = タップで `0`、ホールドで Layer 4（未定義）
- `CTL_T(`)` = タップで `` ` ``、ホールドで LCtrl
- `RCTL_T(-)` = タップで `-`、ホールドで RCtrl

## レイヤー遷移図

```
                   MO(6) ─────────────────────────┐
                   LT(6, `) ──────────────────────┐│
       ┌─ LT(1, SPC) ──→ Layer 1 (ナビ/Fn)       ││
       ├─ LT(1, ENT) ──→        ↑                 ││
       │                  auto mouse OFF           ││
Layer 0├─ LT(2, LNG2) ─→ Layer 2 (設定/F/RGB)     ││
       │                                           ││
       ├─ LT(3, F) ────→ Layer 3 (マウス) 🖱️       ││
       ├─ LT(3, .) ────→        ↑                 ││
       │              Auto Mouse（400ms 自動復帰） ││
       │              LED: HSV_AZURE               ││
       │              PRC_SW: CPI 300 精密モード   ││
       │                                           ││
       └──────────────────→ Layer 6 (記号/数字) ←──┘│
                            スクロールモード有効     │
                            LT(4,0) → Layer 4(未使用)
```
